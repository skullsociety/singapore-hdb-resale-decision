# PropertyProject working notes

When adding, renaming, or removing a script under `scripts/` or `web/`, update the **Script guide** table in `README.md` in the same change. Keep one row per active `.py`, `.ps1`, or `.js` script, with a plain-language purpose. Keep the table in workflow order.

Keep numbered scripts, reports, and model artifacts in the matching `phase_*` subfolder. Preserve the installed Chrome extension folder path until its Chrome installation is deliberately migrated.
